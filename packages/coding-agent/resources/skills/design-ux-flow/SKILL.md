# Skill: design-ux-flow

## When to Use
Apply this skill before implementing screens or user flows to ensure user tasks are intuitive, frictionless, and accessible.

## UX Design Guidelines

1. **User Journey & Task Mapping**:
   - Identify the user's primary Job-to-be-Done (JTBD).
   - Map the end-to-end user path from initial trigger to successful completion.
   - Minimize cognitive load: eliminate unnecessary steps, split complex multi-step forms into progressive disclosure flows.

2. **Usability Heuristics**:
   - Provide immediate visual feedback for all user actions.
   - Match system mental models to real-world expectations.
   - Support user control with clear undo, cancel, and edit capabilities.

3. **Error Prevention & Recovery**:
   - Prevent errors proactively: use smart defaults, clear input constraints, and confirmation dialogs for destructive actions.
   - When errors occur, provide clear, human-readable explanations and actionable recovery paths.
