# Project development logbook

Relay can keep a project-local activity journal at `.relay/memory/logbook/events.jsonl`. The journal is written as work happens and is independent of conversation session files. It records session starts, the first line of each request as a short summary, tool names and outcomes, project files changed through Relay's `edit` and `write` tools, checkpoints, and explicit notes. It does not copy full prompts, tool arguments, command output, or file contents. Common credential patterns in summaries and notes are redacted. On startup it flags a request left open by a process that is no longer running and points to `/logbook history`.

The built-in `/logbook` command shows the most recent events. Use `/logbook note <text>` to save a decision or reflection and `/logbook checkpoint` to add a checkpoint. `/logbook history` also shows recent events. Notes are local project data; common credential patterns are redacted, but review the text before sharing the journal.

The journal writes only in trusted projects. Automatic recording is disabled for `--no-session` runs; explicit notes and checkpoints still work after project trust is established. Symlinked `.relay`, memory, journal directories, and journal files are refused. The append-only file is flushed after each event, and the history command reads only its last 256 KiB. An incomplete final JSONL record is separated from later records so prior entries remain readable. The local `.relay/memory/` directory is ignored by the repository's default `.gitignore`.

This journal is a recovery aid, not a transcript or backup system. It can show what Relay completed before a restart, but it does not preserve uncommitted file contents or guarantee recovery of an in-progress filesystem write. Session transcripts are stored separately. By default they live under `~/.relay/agent/sessions/`, grouped by working directory; `/session` shows the active file, and `--session-dir` changes the location. `--no-session` disables transcript persistence. See [Sessions and Context](sessions.md) and [Project initialization and graph memory](project-memory.md).
